# 音频来源与生命周期 — 星间午后

- 背景音乐：《星间午后》，用户于 2026-09-09 试听后确认采用。原创 MIDI 编曲，由本地 GarageBand 使用经典电钢琴、颤音琴、指弹贝司、南加风情鼓组混音导出。80 BPM、32 小节，循环文件为 96 秒、44.1 kHz 双声道 PCM WAV。
- 文件：`src/renderer/public/audio/starlit-afternoon-loop.wav`；可编辑工程：工作区 `音乐创作/星间午后/星间午后.band`。仅使用已安装库乐队音色，不使用原开源房间项目的第三方背景歌曲。
- 循环版将导出的末尾混响回卷至开头并降低 4 dB；以一个已解码 AudioBufferSourceNode 循环，暂停后从原位置继续。
- 电子琴：正弦基频与少量二、三次谐波、快速起音和自然衰减包络，全部实时合成，无第三方音色采样。它是轻柔的合成琴音，不宣称声学钢琴采样质感。
- 默认不创建播放器也不发声；首次用户点击音乐或琴键时才创建唯一 AudioContext。
- 音乐播放意图与音量由调用层展示；音量偏好由现有设置存储。启动时音乐始终暂停。
- 翻面、视角与主题变化不重建控制器。离开琴键区域应调用 allNotesOff；窗口失焦、进入文字输入区、页面隐藏自动停止琴音。页面隐藏暂停 AudioContext，恢复时延续音乐相位。
- 演奏时音乐平滑降低至 30%，全部琴键释放后恢复。琴音独立于音乐播放开关和音乐音量。
- 应用卸载调用 dispose，释放播放节点、加载请求、事件和音频上下文。

自动化检查只能验证状态与信号生成，不能代替实际音量、音色和连续播放听音验收。
