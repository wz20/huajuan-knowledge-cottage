# v10 材质配色

视觉参考：实际浏览原站取得的 `evidence/reference-v10/source-day.png` 与 `source-current.png`。日夜共用基础材质，夜晚明暗由应用光照控制。

本目录所有 PNG 由 `assets/blender/palette-v10.py` 中数学木纹／细织纹函数独立生成。没有复用原站 Denis Wipart 的第三方付费纹理与节点，没有原房间日夜烘焙图。v9 自制的 Normal、Roughness 和实际 UV 接线保留。

| 表面 | sRGB 基色 | 说明 |
|---|---|---|
| 木框／家具 | #C3977D | 桃木粉棕，宽弯年轮 |
| 地板 | #CE9E80 | 稍亮桃木，板缝仍由几何产生 |
| 墙面 | #E9ECF5 | 干净微冷白 |
